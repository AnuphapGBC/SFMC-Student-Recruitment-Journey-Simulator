# Pek Chansatit — Portfolio Site

A lightweight, responsive static portfolio prepared for GitHub Pages.

## Portfolio direction

The site is intentionally focused on:
- Power Platform and RPA
- AI-assisted workflow automation
- sanitized enterprise automation case studies
- public full-stack projects that reviewers can inspect on GitHub

No employer-confidential code, internal URLs, customer data, or credentials are included.

## Files

- `index.html` — portfolio content and structure
- `styles.css` — responsive dark/navy visual design
- `script.js` — small progressive enhancement for navigation/year

## Recommended final repository

Create a new **public** repository named:

```
AnuphapGBC.github.io
```

Then place these three site files at the repository root. GitHub Pages user sites publish from that repository at:

```
https://AnuphapGBC.github.io
```

Alternatively, create a repository named `portfolio` and enable GitHub Pages from `main` / root.

## Before publishing

Optional additions that would improve the portfolio further:
1. Add a professional headshot or leave the current text-first hero.
2. Add a current PDF resume under `assets/` and a Resume button.
3. Add LinkedIn once the exact profile URL is available.
4. Add screenshots/GIFs to the strongest project cards.
5. Add one or two Copilot Studio demos after they are fully built and can be shown honestly.

## Design goals

- fast loading
- no framework or build step
- no external JavaScript dependencies
- mobile responsive
- recruiter-friendly content hierarchy
- straightforward GitHub Pages deployment
